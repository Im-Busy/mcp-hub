# Project Skills

Place project-specific skills in this directory. Each skill goes in its own subdirectory.

## Skill Structure

```
skills/
└── skill-name/
    └── SKILL.md    # The skill definition
```

## SKILL.md Template

```markdown
---
description: Short description shown in the skill picker
---

# Skill: skill-name-here

## When to Load

Describe the triggers — what phrases or situations should cause the agent to load this skill.

## Instructions

The detailed instructions for the agent when this skill is active.
```
